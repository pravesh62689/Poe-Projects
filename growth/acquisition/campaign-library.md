# Growth Campaign Library

**Campaign Taxonomy:** Multi-channel outbound & inbound playbooks for developer utility adoption.  
**Budget:** ₹0.00 / $0.00 (Pure organic technical content & developer utility marketing).

---

## Campaign 1: "The Clean Receipt Challenge" (OCR-Doc-Bot)
- **Target Audience:** Small business owners, freelance contractors, bookkeepers handling messy expense photos.
- **Hook:** "Why do mobile receipt scanners hallucinate totals? How projection profile deskewing and line-item reconciliation fix the math."
- **Core Asset:** Guide: `https://poe-developer-suite.pages.dev/guides/how-to-photograph-receipts/` and live benchmark comparison.
- **Distribution:** Indie Hackers, bookkeeping subreddits, accounting template repositories.
- **Conversion Path:** User reads photography checklist -> Clicks "Parse Sample Receipt on Poe" -> Experiences instant JSON extraction with arithmetic check.
- **Measurement:** Inbound clicks from bookkeeping threads; first-task OCR uploads.

---

## Campaign 2: "ReDoS Defuser" (Regex-Gen-Tester)
- **Target Audience:** Backend engineers, Node.js/Python developers writing user-input validation patterns.
- **Hook:** "Is your regex vulnerable to catastrophic backtracking? Test your email and URL patterns against ReDoS attacks."
- **Core Asset:** Static tool guide: `https://poe-developer-suite.pages.dev/regex-tester/` + safe-regex test cases.
- **Distribution:** Dev.to, Hashnode, `r/programming`, Hacker News "Show HN" (when permitted).
- **Conversion Path:** Interactive test examples in article -> User clicks "Test Your Pattern in Regex-Bot" -> Receives breakdown with AST analysis.
- **Measurement:** Github star referrals, web CTR to Regex-Gen-Tester.

---

## Campaign 3: "Instant SQLite Sandbox" (English-To-SQL)
- **Target Audience:** Junior developers, data analysis bootcamp students, business analysts learning SQL joins.
- **Hook:** "Generate SQL, seed a temporary in-memory database, and see real tabular results directly in chat without configuring a database server."
- **Core Asset:** Guide: `https://poe-developer-suite.pages.dev/guides/sql-joins-with-sample-schema/` + SQLite vs Postgres comparison.
- **Distribution:** SQL learning forums, student developer discords, bootcamp alumni boards.
- **Conversion Path:** Free sample schemas provided in guide -> User clicks "Try on SQL-Bot" -> Bot creates in-memory DB and streams table.
- **Measurement:** Inbound web clicks, multi-turn retention on SQL-Bot.
