## 2. Channel Execution Protocols

### 2.1 Poe-Native Compounding Loop
- **Lever 1: Category Co-Usage Affinity.** Because `English-To-SQL` and `Regex-Gen-Tester` reside in **Programming**, users who engage with both bots teach Poe's recommendation algorithm to cross-promote them under "Related Bots".
- **Lever 2: Fast Response Times.** Cloudflare Worker edge execution (< 30ms) ensures near-instant response delivery, protecting user ratings from latency churn.
- **Lever 3: Zero Dead-Ends.** When a query fails (e.g. blurred image or missing schema), the bot never responds with a generic error; it provides an immediate recovery prompt and suggested reply.

### 2.2 Technical Open-Source Credibility
- Rather than promotional marketing, publish our ground-truth evaluation harness (`qa/live-ocr`) as an open reference for Tesseract accuracy benchmarking on faded thermal receipts.
- Developers trust working code and reproducible evidence over marketing claims.

### 2.3 Community Engagement Rules
- Strictly prohibit unsolicited commercial posts, repetitive spam comments, or bot-generated forum replies.
- Team members may only share links when directly answering an existing technical question where our bot's verified output provides the exact solution.
