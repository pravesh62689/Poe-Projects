# Apex Forge Technology — Community Participation & Anti-Spam Policy

**Document Version:** 1.0.0  
**Enforcement Standard:** Zero tolerance for automated posting, link stuffing, astroturfing, or fake engagement.

---

## 1. Strictly Prohibited Behaviors
1. **Zero Automated Bot Posting:** Never write or deploy scripts to auto-reply to Reddit, Stack Overflow, X, Discord, or GitHub discussions.
2. **Zero Fake Engagement:** Never purchase or generate fake likes, upvotes, follows, Poe messages, or positive testimonials.
3. **Zero Link Farms / Comment Spam:** Never leave unsolicited links on blog comments, forums, or irrelevant subreddits.
4. **Zero Cloaking or Astroturfing:** Never pretend to be an unbiased customer praising Apex Forge Tools.

---

## 2. Permitted Value-First Developer Engagement
1. **Answering Technical Questions:** When an engineer asks for help with a catastrophic backtracking regex or a tricky SQL JOIN on Stack Overflow or Reddit:
   - Provide a complete, helpful, standalone answer with the code directly in the comment.
   - Mention the free tool only as an optional testing playground at the end: *"If you want to test this regex against edge cases, you can dry-run it in our free Apex Forge sandbox: [link]"*.
2. **Open-Source Contribution:** Submit bug reports, pull requests, and benchmark fixtures to relevant open-source libraries.
3. **Transparent Identity:** Always disclose affiliation with Apex Forge Technology when discussing the tools.
