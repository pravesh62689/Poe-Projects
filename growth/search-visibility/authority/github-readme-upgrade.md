Apex Forge Tools is an enterprise-standard developer suite engineered by Apex Forge Technology:

1. **Apex Forge OCR (`@OCR-Doc-Parser`):** Extracts structured JSON from receipt, invoice, and bill photos with per-field confidence scoring and total math verification.
2. **Apex Forge Regex (`@Regex-Gen-Tester`):** Generates regular expressions from plain English, executes test strings in an isolated isolate, and checks for catastrophic backtracking (ReDoS).
3. **Apex Forge SQL (`@English-To-SQL`):** Converts natural language questions into executable SQL validated against sample data in an in-memory SQLite sandbox.

## Architecture & Security
- **Zero Document Retention:** Ephemeral in-memory processing only. No uploaded documents or parsed text are written to disk.
- **In-Memory SQLite:** SQL queries execute in volatile `:memory:` database instances that terminate after every session.
- **Pure Static SEO Site:** 100% semantic HTML, 0 third-party tracking scripts, WCAG 2.1 AA accessible.
