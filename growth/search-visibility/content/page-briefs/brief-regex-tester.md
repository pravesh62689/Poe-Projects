## 2. Core Content & Utility
- **User Task:** Describe desired string pattern matching in natural language, generate the regex, and immediately test positive and negative strings with capture group inspection.
- **Required Inputs:** Plain English description + list of test strings (positive matches and negative rejects).
- **Expected Output:** Tested regex pattern, explanation of regex tokens, full match highlights, captured group values, and ReDoS heuristic evaluation.
- **Unique Value Proof:** Real-time isolate execution of positive and negative cases + static analysis of catastrophic backtracking risks `(a+)+`.
- **Known Limitations Disclosed:** Format validation is not business validity (e.g. matching an email regex does not verify that the mailbox exists). Static analysis catches common ReDoS patterns but cannot guarantee complete immunity.
