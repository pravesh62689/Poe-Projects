Privacy Invariant

Zero-Retention Privacy Policy

Effective Date: September 2026

1. Core Architecture: Ephemeral Execution

Our bots operate under a strict zero-retention invariant. When you send an image to OCR-Doc-Parser, regular expressions to Regex-Gen-Tester, or DDL schemas to English-To-SQL:

  • All payloads are processed ephemerally in RAM.
  • No raw images, OCR extracted text, SQL tables, regex strings, or personal documents are stored to disk, databases, object storage, or persistent logs.
  • Once the HTTP Server-Sent Event (SSE) stream terminates, in-memory buffers are immediately garbage collected.

2. Telemetry & Analytics

We do not track user identities, IP addresses, browser fingerprints, or message contents. Our telemetry records aggregate, anonymous operational counters only:

  • Task outcome status (success, partial, failure)
  • Execution latency buckets (e.g., <1s, 1-3s, 3-10s)
  • High-level categorical error codes (e.g., blur_detected, syntax_error)

3. Poe Platform Privacy

The bots operate as server bots on the Quora Poe platform. Interaction history within the Poe application is governed by Poe's Privacy Policy. We do not have access to your personal Poe account profile, billing details, or chat history beyond individual incoming query turns.

4. Open Source & Verifiability

The code powering these services is open source and auditable. Security researchers and users can independently inspect our repository to verify the absence of persistence layers or data collection sinks.
